# n8n Workbench for VS Code & Antigravity IDE

Open, monitor, and interact with **n8n** directly inside your editor.

![n8n Icon](media/icon.png)

## Features

- ⚡ **Open n8n in Editor Tab**: Embed the full n8n workflow canvas directly in an editor tab side-by-side with your code and JSON files.
- ◫ **Split Editor View**: Open n8n beside your active file to compare workflows, edit scripts, and inspect schemas simultaneously.
- 🟢 **Live Server Health Monitoring**: Real-time status indicator in the bottom status bar and Activity Bar showing whether n8n is Online or Offline with latency.
- 🚀 **One-Click Server Starter**: Launch your local n8n instance (`npx n8n`) in an integrated terminal with a single click.
- 🌐 **External Browser Quick Access**: Easily pop out to your system's default browser or Simple Browser anytime.
- ⚙️ **Configurable URL**: Works with default `http://localhost:5678` or any remote/cloud-hosted n8n instance.

## Keyboard Shortcuts

- `Ctrl + Alt + N` (Windows/Linux) / `Cmd + Alt + N` (macOS): **Open n8n in Editor Tab**

## Extension Settings

This extension contributes the following settings:

* `n8n.url`: The URL of your n8n instance (Default: `http://localhost:5678`).
